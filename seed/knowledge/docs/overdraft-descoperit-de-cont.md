# Overdraft (descoperit de cont)

## At a glance (structured data)
- **Slug:** overdraft-descoperit-de-cont
- **Category:** personal_loan
- **Summary:** Revolving RON overdraft facility of up to 6 net monthly salaries/pensions for customers whose income is paid into a Raiffeisen current account; variable rate IRCC + 9.99% (15.56%), or IRCC + 4.99% (10.56%) with ZERO Simplu; interest only on the amount used.
- **Interest rate / return:** 15.56 % p.a. variable (IRCC + 9.99% margin) (as of 2026-10-01 (cost sheet date)). As of 01.10.2026: IRCC 5.57%; standard margin 9.99% -> 15.56% (DAE 22.84%). With ZERO Simplu package: margin 4.99% -> 10.56% (DAE 14.08%). Unauthorised overdraft = rate + 3%.
- **Minimum amount:** not specified / see details
- **Currencies:** RON
- **Terms:** Revolving facility; renewal per contract (not retrieved)
- **Good for:** short_term_liquidity, unexpected_expenses

### Key features
- Limit up to the equivalent of 6 net salaries/pensions, RON only
- Interest only on used amounts; no fees if the limit is not used
- Variable rate = IRCC (5.57% on 01.10.2026) + bank margin: 9.99% standard -> 15.56%, DAE 22.84%; ZERO Simplu holders get the margin reduced by 5 pp to 4.99% -> 10.56%, DAE 14.08% (example)
- Limit can be increased when income grows; Premium package: 0% interest on first 500 lei used
- Requested in any branch; income verified through ANAF consent

### Fees
- **Analysis fee:** 0 lei - Representative example
- **Unused limit:** No fees or commissions
- **Unauthorised overdraft:** Interest rate + 3 percentage points
- **ZERO Simplu package fee used in the DAE examples:** 12 lei - Quoted from the examples; the page does not say whether this is per month or for the whole 3 months

### Eligibility
- Individual aged 21-65
- Salary or pension paid into a Raiffeisen current account with debit card
- Income >= minimum net wage; >= 3 months at current job; no loans repaid with delays
- Consent to ANAF income consultation; ID card
